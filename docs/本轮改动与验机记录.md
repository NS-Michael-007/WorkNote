## 二、启动页与应用图标（本轮追加）

需求：启动页面要有和 App 风格一致的图标形象。

做法：
- **重绘应用标记** `res/drawable/ic_launcher_app.xml`（纯矢量，任意分辨率不糊）：微信绿 `#07C160` 圆角方底 + 白色便签纸（右上折角、三条绿色横线）+ 右下红色未处理角标（`#FA5151` 里一个白色「!」），正好对应「便签 + 不处理就提醒」这两层含义。角标已收进底板轮廓内，避免被系统裁切或看成贴纸溢出。
- **新增启动页** `SplashActivity` + `activity_splash.xml`：居中 132dp 图标、下面「工作便签提醒」24sp 粗体、再下一行「不处理就关不掉的强提醒」（英文 `Stays on screen until it is handled`），底部「版本 1.0.0」；内容做 420ms 淡入 + 上浮动画。
- **主题** `Theme.WorkNote.Splash`：`windowBackground` 指到 `bg_splash.xml`（底色 + 居中图标），冷启动第一帧就有图，不闪白屏；同时配 `windowSplashScreenBackground` / `windowSplashScreenAnimatedIcon`，让 Android 12+ 的系统 Splash 也用同一张图、同一个底色，两段衔接不跳色。

- 700ms 后自动进主界面，点一下屏幕也能立刻跳过；夜间模式用 `@color/page_bg` 自动切成深色底。
- 顺手把「编辑页贴背景图」这处遗漏补上（`NoteEditActivity` 加 `ThemeHelper.applyPageBackground`）。

## 三、背景图「只主界面显示」的修复

现象：设了背景图后，只有主界面透出图，日程和「我」页几乎看不到。

原因两条：
1. 背景图只铺在各 Fragment 自己的根布局上，三页各铺一份；`fragment_profile.xml` 的 ScrollView 还写死了 `@color/page_bg` 不透明底，把图盖住了。
2. 遮罩原来是 `#EE`（约 93% 不透明）的纯白雾，等于把照片糊成一层浅灰。主界面有大片空态区域所以看得出一点纹理，日程和「我」页全是白卡片，就完全看不见。

改法：
- 背景图改成铺在 **MainShellActivity 整个外壳的根布局**上，三个 Tab 共用一张底图；Fragment 内部不再各铺一份，`fragment_profile.xml` 的写死底色删掉。
- 底图先做 **虚化**（1/12 缩小再双线性放大回来，近似高斯模糊），遮罩降到 `#9E`（约 62%）；深色模式用 `#B4` 深灰雾。照片明显能看见，文字也不糊。
- 虚化结果按「文件路径 + 大小 + 修改时间 + 是否深色」缓存，切页不再重复解码。
- 日程页日期行原本是透明底（以前看着像白卡，是被那层 93% 白雾"糊"出来的），现在露底会显得花 → 给列表加了一层半透明磨砂面板（`bg_frost_panel`，`#A6FFFFFF` / 夜间 `#A61E1E1E`）＋每行 1dp 分隔线；**只有设了背景图时才铺面板**，纯色底仍保持原来的样子。

真机验证（用一张高对比条纹测试图，验完已清掉、恢复默认纯色）：
1. 主界面：整页铺满底图，便签卡片正常。
2. 日程页：底图透出，日期行有磨砂面板与分隔线，文字清晰。
3. 「我」页：底图铺满，白色设置卡片浮在图上，间隙能看到底图。
4. 清掉背景图后回到纯色：日程为 `#EDEDED` + 细分隔线，与原来的观感一致；「我」页恢复原样。

## 六、图标与启动页二次设计（本轮）

问题：第一版图标是纯色平铺 + 手绘矢量，桌面上一看就"廉价"；启动页是浅灰底 + 图标 + 两行字，没有品牌感，也没有入场节奏。真机放大核对后还发现两个硬伤。

**桌面图标（重点修硬伤 + 提质感）**
- 原来 `android:icon` 直接指向矢量文件，属于"老式图标"，桌面（realme 这套 launcher）会把它塞进固定大小的白色底板里，四周留一圈白边，和旁边微信那种圆角方块不一致。→ 改成**自适应图标**：`mipmap-anydpi-v26/ic_launcher.xml`（background + foreground + monochrome 三层），桌面按自己的形状（圆角方 / 圆 / 水滴）裁切，和系统里其它 App 完全一致；Android 13 的主题图标（单色层）也一并给了。
- 第一版自适应图标把红角标摆到了安全区外（角标中心离画布中心 27.6，加上半径后 40.4，超过安全半径 36），真机上角标右下被裁掉一点点。→ 按**安全圆**重新排比例：便签四角和角标外沿全部收在半径 33 以内，任何桌面形状都不会切到。
- 质感：底板改成左上亮 → 右下深的绿色渐变，加一层顶光、一层底部压暗；便签白改成微渐变白、加双层投影；折角双色渐变；角标改成红色径向渐变 + 白色描边圈，把「!」压成贴纸感。
- 角标位置从"便签外侧"改到"压住便签右下角"，构图更紧凑，也不再需要为了塞下角标而把便签缩很小。

**启动页（要"有感觉"）**
- 底色：从浅灰纯色换成**品牌绿竖向渐变**（#15D27A → #0AA85C → #045C36），中上部叠一团 230dp 的白色柔光，顶部再压一层极淡白。冷启动第一帧就是这张图，不会再闪白。
- 构图：白色圆角卡片（160dp，圆角 32dp，12dp 投影）托住图标（106dp），下方白色标题（26sp、字距 0.1）+ 浅绿口号 + 底部版本号。
- 入场动画改成**四拍**：卡片从 0.88 缩放 + 上浮 24dp 带 OvershootInterpolator 回弹出来 → 标题晚 140ms 上浮 → 口号晚 280ms → 版本号晚 420ms 淡入；约 1.4 秒后淡出进主界面，点屏幕可跳过。
- 系统启动画面（Android 12+）：背景改成同一个品牌绿，动画图标用"白色便签 + 红角标"的纯 glyph（自适应图标前景层），不再用绿色方块（绿块压在绿底上等于看不见），两段衔接不跳色。
- 状态栏透明、导航栏用深绿并切成浅色手势条，避免底部出现一条浅灰。

验证：真机截图核过系统 Splash 帧、完整启动页、桌面图标（放大 4 倍看角标有没有被裁）；`am start` 后 `dumpsys window` 的 `mFocusedApp` 已是 `MainShellActivity`，说明 1.4 秒后确实进了主界面，logcat 无 FATAL。
