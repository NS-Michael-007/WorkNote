# 关联日期 / 提醒时间改成「年月日 + 今天」（三端）

日期：2026-11-08
需求原话：「修改，关联日期（日期选择左右，变更成可选择年月日，增加当天的）提醒方式（定时提醒加入年月），三个软件上都需要加这些。」

## 一、需求怎么落地

| 需求片段 | 落地方式 |
|---|---|
| 关联日期「日期选择左右」 | 原来的 `DatePickerDialog` 是日历盘，只能靠左右箭头翻月、看不到年份，效率低。改成 **年 / 月 / 日 三段滚轮**，三段都能直接转，想改年份直接转年轮 |
| 「变成可选择年月日」 | 滚轮里年份范围 1970–2100，月份 1–12，日随年月自动收缩（2 月只到 28/29 日），选中行和上下相邻行都带单位（`2026年 / 11月 / 8日`） |
| 「增加当天的」 | 对话框底部三个按钮：**今天 / 取消 / 确定**。「今天」一下把日期落到当天，时分保持不变；点完立即回填，不用再确认 |
| 提醒方式「定时提醒加入年月」 | 提醒时间原来只有时/分（`TimePickerDialog`），现在改成年月日 + 时分五段滚轮，提醒时间那一行也按 `2026年11月8日 09:00` 显示，不再是「今天 09:00」这种看不出年份的写法 |
| 「三个软件上都需要加」 | Android 已改完并在真机验证；iOS 改完（未编译）；鸿蒙补出编辑页并改完（未编译） |

## 五、本轮踩到并修掉的坑

1. **PowerShell 双引号 here-string 会吃掉 `$s` / `$d`**。写 Android 格式串时用了 `@"..."@`，`%1$s（今天）` 被插值成 `%1（今天）`，`%1$d年` 变成 `%1`。结果 `String.format` 在 `Conversion = '（'` 处抛 `UnknownFormatConversionException`，一进编辑页就崩（`TimeUtil.kt:87` → `NoteEditActivity.updateText:126` → `onCreate`）。修法：改用脚本文件 + 单引号/文件写入，改完用脚本逐条读回核对；以后**禁止**用双引号 here-string 写带 `%1$` 的资源串。
2. **`NumberPicker.setFormatter` 只给上下相邻行加单位，中间选中行是裸数字**（`2026` 混在 `2025年 / 2027年` 之间）。修法：全部改用 `setDisplayedValues(Array<String>)`，选中行和相邻行同一套文案。
3. **`setDisplayedValues` 与 `maxValue` 的顺序**：必须先 `displayedValues = null`、再改 `minValue/maxValue`、最后贴新数组，否则 2 月收缩时抛 `IllegalArgumentException`。
4. **滚轮不给固定高度，对话框会被撑成一整屏**：`WRAP_CONTENT` 下 `NumberPicker` 按「能放下全部条目」去量，五段滚轮时对话框高到 1900px 以上。修法：每段固定 180dp，行高也固定。
5. 时分那一行左边留一个与「年」等宽的空白占位，`时 / 分` 才会正好落在 `月 / 日` 两列下面，视觉上不歪。
