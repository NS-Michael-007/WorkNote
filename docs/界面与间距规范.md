# 工作便签提醒｜界面与间距规范（按代码实际实现整理）

> 单位：dp（安卓）。全部数值集中在 `res/values/dimens.xml`，颜色集中在 `res/values/colors.xml` 与 `values-night/colors.xml`。
> 改样式只改这两处，不要在单个布局里硬写数值。

## 一、页面结构（三段式，全 App 统一）

```
┌──────────────────────────────┐
│ 状态栏（系统，颜色 = bar_bg）   │  fitsSystemWindows 自动让位
│ 顶部标题栏 48dp                │  主界面 / 日程 / 我 各自一个标题栏
├──────────────────────────────┤
│ Spacer 12dp                    │  → 标题栏到第一组内容
│ 内容区（单列纵向，只上下滚动）   │
│ Spacer 12dp                    │  最后一条到 Tab 栏
├──────────────────────────────┤
│ 底部 Tab 56dp + 系统手势条留白   │  主界面｜日程｜我，三栏等宽
└──────────────────────────────┘
```

## 七、交互规则（硬约束）

1. 单列纵向布局、全部左对齐，**禁止左右横向滚动**。
2. 手机没有鼠标，桌面版那种"悬浮态"一律用按下态（水波纹）。
3. 主界面列表排序：待处理（已提醒）→ 待提醒 → 已延后 → 已完成 → 已归档，同组按提醒时间升序。
4. 日程页：1 号到月末逐行罗列，点行展开当天便签，箭头旋转 90° 表示已展开。
5. 强提醒卡片：无 ×、点遮罩不关、返回键不关，只能点便签自带按钮。
6. 每个 Tab 一个独立文件，改哪个页面只动哪个文件。
